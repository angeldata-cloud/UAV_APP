# PowerPoint 實際截圖清單

這份清單供後續製作兩份 16:9、淡綠色、大字、長輩友善簡報。現在先收集真實畫面，不製作假截圖。請依編號一次提供一張；每張收到後會先檢查清晰度、內容與是否需要遮蔽個資，再索取下一張。

## 截圖共通規則

- 電腦截圖請使用瀏覽器原始大小，盡量不要先裁切；之後簡報會放大重點區域。
- 手機截圖請保留完整螢幕邊界與 Safari／App 必要操作區。
- 可以遮住密碼、Email、通知、頭像與其他私人 Repository；不要遮住本專案名稱、按鈕名稱或狀態。
- 同一張圖只呈現一個主要動作；游標盡量不要擋住文字。
- GitHub 若改版，請以爸爸實際看到的畫面為準，不必刻意找和舊教學相同的介面。
- 檔案請存到表格指定的 Repository 資料夾與檔名。
